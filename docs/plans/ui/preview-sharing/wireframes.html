The header Share button is not this: it opens V2.5 Taksha Hosting and stays hidden until then. Spec: screens.md.

  1. Today the router answers these with JSON ({"status":"error","message":…}). For a browser (Accept: text/html) it should answer with these small pages instead, same status codes (401 expired or turned off, 503 asleep, 401 private). Static HTML in the router, no external assets, no user data.
