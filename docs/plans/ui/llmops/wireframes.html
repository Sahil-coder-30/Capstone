LLM quality and cost screens

llmops-evals-cicd-plan.md has no user-facing screens: evals run in CI, traces live in Langfuse, dashboards in Grafana. This board is a proposal for one summary page in the admin portal, the "Quality and cost" tab of AI runs, so the numbers the plan produces (eval scores, cost per request, cache hits, routing) sit next to the rest of the AI data. Build it only if Grafana and Langfuse are not enough. Spec: screens.md.
