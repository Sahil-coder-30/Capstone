  1. Activity bar (48 px, App.scss .activity-bar) at the left of the Code workspace: Explorer and Source Control. Ember indicator on the active item, ember badge with the change count. Ctrl+Shift+G opens it.
  2. Commit box: multi-line, placeholder names the branch, ✨ (G6) writes a message from the staged diff. Split button: Commit, caret opens SC-5 menu.
  3. Groups: Merge Changes (only when merging), Staged Changes, Changes. Row: file name, folder in disabled text, status letter in VS Code colours. Deleted files struck through.
  4. Row actions on hover: open file, discard, stage (or unstage in Staged). Click the row opens the diff. Same on the group header for all files.
  5. Diff tab named "store.js (Working Tree)" or "(Index)" for staged. Monaco DiffEditor, right side editable, side by side or inline.
  6. Status bar: branch (asterisk when dirty) opens the branch picker, behind and ahead, Sync, linked repo on the right (opens GitHub).
