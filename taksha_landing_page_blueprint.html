02
hero
Hero — the thesis
Full-viewport · dark canvas
▾
Headline: "Describe your app. Taksha builds, tests, and fixes it — automatically."
Sub: "A 5-agent AI pipeline on Kubernetes. One prompt → production-ready React app."
Badge pill: "Built on Mistral Devstral"
Primary CTA: "Start building"
Ghost CTA: "Watch demo"
Stat strip: "5 agents · Kubernetes sandboxes · Self-healing"
Node lattice animation (SVG)
AI Studio ref: big centered headline, subtle animated background, two-button CTA, no hero image. Let the copy do the work.
03
demo
Live prompt bar
The Google AI Studio signature move
▾
"Try it — describe what you want to build" → show live agent output stream in a terminal-style pane
Large prompt textarea
Real-time agent output stream
Example prompts: chips ("Todo app in React", "REST API with auth")
Typewriter animation on output
Agent step indicators (Planner → Builder → Reviewer...)
Split pane: prompt left · output right
This IS the Google AI Studio move — show the actual interface before signup. Interactive demo = highest conversion element on dev tools landing pages.
04
flow
How it works
3-step clarity section
▾
Step 1: "Describe" → Step 2: "Build" → Step 3: "Deploy"
3 horizontal step cards
Icon per step (ti-message, ti-cpu, ti-rocket)
Connector arrows between steps
Each card: 1-line title + 2-line description
Scroll-triggered reveal animation
Keep it brutally short. 3 steps max. Developers hate fluff. This section exists to kill the "but how does it actually work?" objection.
05
arch
Agent pipeline diagram
The technical depth moment
▾
Show the 5-agent LangGraph flow: Planner → Builder → Reviewer → Tester → Debugger (master orchestrator)
Animated agent flow diagram
Each agent: name + one-line role
Kubernetes pod visual below the flow
RAG / MongoDB Vector Search callout
File API sidecar mention
SVG with pulse animation on active node
This is your technical credibility section. Devs evaluating tools want to see the architecture before they commit. Don't hide it.
06
features
Features grid
6-card bento layout
▾
6 features in a 3×2 bento grid — 1 large hero card + 5 smaller ones
Self-healing code (hero card)
Kubernetes sandbox per user
Real-time browser error capture
Surgical patchFile edits
Export validation (JSX guard)
RAG-powered context memory
Bento CSS grid: 2 cols × 3 rows, 1 card spans 2
AI Studio ref: dense bento cards on dark bg. Each card = icon + feature name + 1-sentence description. No bullet lists inside cards.
07
stack
Tech stack strip
Developer trust · logo parade
▾
"Built on tools you already trust"
Logo strip: LangGraph, Mistral, MongoDB, Kubernetes, React, Vite
Muted on-dark treatment (opacity 50%, hover 100%)
Auto-scroll marquee on mobile
Infinite marquee CSS animation
Don't put this too early — it's a trust amplifier, not a hook. Works best after the agent pipeline section when devs already understand what you built.
